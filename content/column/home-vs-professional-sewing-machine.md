ミシンを選ぶとき、最初に迷うのが「家庭用」と「職業用」の違いです。名前からは「趣味用」と「プロ用」のように聞こえますが、実際は**得意なことが違う、別の道具**と考えるほうが近いでしょう。

## いちばんの違いは「できる縫い方の数」

家庭用ミシンは、直線縫い、ジグザグ縫い、ボタンホール、飾り縫いなど、1台でいろいろな縫い方ができます。布端のほつれ止めも、ボタン穴も、この1台で済ませられます。

職業用ミシンは、**直線縫いしかできません**。ジグザグもボタンホールもありません。そのかわり、まっすぐ縫うことについては、家庭用とは別物の仕上がりになります。

| | 家庭用ミシン | 職業用ミシン |
| --- | --- | --- |
| 縫い方 | 直線・ジグザグ・ボタンホール・模様 | 直線のみ |
| 縫い目 | 実用上は十分 | まっすぐで、糸の締まりがよい |
| 厚地・重ね縫い | 機種によっては苦手 | 得意 |
| スピード | ゆっくり〜中速 | 速い |
| 布端の始末 | ジグザグなどで可能 | 別にロックミシンなどが必要 |

## 縫い目がきれいになる理由

職業用ミシンは、針が上下にしか動きません。ジグザグのために針を左右に振る仕組みを持たないぶん、針のぶれが少なく、縫い目がまっすぐ整います。

布を送る力と、押さえる力も強めです。デニムの裾のように生地が何枚も重なる段差でも、止まらずに進みやすいのはこのためです。シャツの衿まわりやポケット口など、ステッチが表から見える場所ほど、違いがはっきり出ます。

## スピードと、使い心地

職業用ミシンは、家庭用よりも速く縫える機種が多く、スカートの脇やカーテンのような長い直線で差がつきます。「速いと怖い」と感じるかもしれませんが、足元のコントローラーで踏み加減を調整できるので、ゆっくり縫うこともできます。

膝で押さえ金を上げ下げするレバー（ニーリフター）が付いた機種も多く、両手で布を持ったまま方向を変えられます。慣れると手放せなくなる機能です。

## どちらを選ぶか

**家庭用ミシンが向いている人**

- これから洋裁をはじめる
- 布小物や入園入学グッズが中心
- ボタンホールや飾り縫いも1台で済ませたい
- 置き場所を1台分にしたい

**職業用ミシンが向いている人**

- 洋服を本格的に作りたい
- 帆布やデニムなど厚手の生地をよく縫う
- 家庭用ミシンの直線縫いに物足りなさを感じている
- 布端の始末は別のミシン（ロックミシン）で行う

職業用ミシンを使う人の多くは、布端の始末用にロックミシンを組み合わせます。くわしくは[ロックミシンとは？初心者向けに解説](/column/what-is-overlock-machine)をご覧ください。

## 迷ったら、両方を使い比べる

カタログの数字を見比べるより、同じ生地を両方のミシンで縫ってみるほうが、違いはすぐにわかります。縫い目の表情、音、布を送る感触。自分が作りたいものに必要かどうかは、手を動かすと判断できます。

![Nippori Share Base の棚。手前に家庭用のコンピューターミシン、奥に職業用ミシンが並んでいます](/photo/shelfHome)

Nippori Share Base には、家庭用ミシンと職業用ミシンの両方を置いています。家庭用は JANOME の CANTARE TJ-1SP と brother の COMPAL 700。職業用は JUKI の SL-3700 とシュプール30デラックス、JANOME の haute couture ecru 2000 です。家庭用と職業用の縫い目を、自分の生地で見比べられます。

ミシンを持ち帰るレンタルではなく、スペースに来て半日や1日の枠で使う形です。機種ごとの特徴は[設備・道具の一覧](/equipment)に、使い方と料金は[ミシンのページ](/sewing-machine)にあります。
