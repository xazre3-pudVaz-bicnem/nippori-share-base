お手持ちのTシャツの裾を見てください。表には平行な2本のステッチ、裏返すと糸がループ状に渡っているはずです。この縫い目が「カバーステッチ」。専用のミシンで縫われています。

## カバーステッチは「伸びる裾上げ」

ニット生地の裾を普通のミシンの直線縫いで上げると、着たり脱いだりするうちに糸が切れてしまいます。生地は伸びるのに、縫い目が伸びないからです。

カバーステッチは、裏側のループ糸に余裕があるため、**生地と一緒に伸び縮みします**。しかも裏のループが裁ち端を覆うので、折り上げた端の始末も同時に済みます。裾上げと端処理を一度に行える、ニット専用の仕上げ方です。

## ロックミシンとの違い

名前が並べて語られることが多いのですが、役割ははっきり分かれています。

| | ロックミシン | カバーステッチミシン |
| --- | --- | --- |
| 役割 | 布端をかがる・ニットを縫い合わせる | 裾・袖口・襟ぐりを仕上げる |
| 刃（メス） | あり。端を切りながら縫う | なし。布を切らない |
| 縫える場所 | 布の端だけ | 布の途中にも縫える |
| 表から見た縫い目 | 端をくるむかがり目 | 平行な2本（または3本）の線 |

Tシャツづくりで言えば、**脇や袖を縫い合わせるのがロックミシン、最後に裾と袖口を上げるのがカバーステッチミシン**です。

## できること

- **裾上げ**：Tシャツ、スウェット、レギンスの裾
- **袖口・襟ぐりの始末**：折り返してステッチで押さえる
- **飾りステッチ**：切り替え線の上を叩いて、スポーツウェアのような見た目に
- **チェーンステッチ**：針を1本にして縫う、鎖状の縫い目。デニムの裾上げなどに使われる

メスがないので、布の真ん中にも縫えます。ゴムテープを縫い付けたり、バインダーという部品を使って襟ぐりを布でくるんだりと、応用の幅は広めです。

## なぜ「あと一歩」のミシンなのか

カバーステッチミシンがなくても、服は完成します。裾を手でまつったり、伸びる糸を使って直線縫いしたりする方法もあるからです。

それでも、カバーステッチで仕上げた裾は、見た目がまったく違います。手づくりの服が「既製品のように見えない」理由の多くは、じつは裾にあります。最後のひと手間を変えるだけで、作品の印象が引き締まります。
