## 確認できていないこと（サイトに書いていない）

次の項目は、わかり次第 `lib/site.ts` などに追加してください。分かるまでは書かないでください。

- [ ] **営業日・定休日**（カレンダーに出る日が予約可能日、としか分からない）
- [ ] **駅からの徒歩分数**（推測で書かない）
- [ ] **駐車場・駐輪場の有無**
- [ ] **設備の台数**、スペースの**面積・定員**
- [ ] **通常利用の決済方法**（現金・カード・電子マネー）
- [ ] **レーザー加工機・カッティングマシーン**の機種、使える素材、料金、予約方法
- [ ] **期間限定ミシンの設置期間**
- [ ] **メンターサポートの内容と料金**（制度があることは 102 で確認。HP のデータ内に「¥1,500」の記載があるが、画面には表示されていない）
- [ ] **運営メンバーの名前・肩書・経歴**（/about と記事の著者欄に載せると信頼性が上がる。ご本人から提供されたものだけ載せる）
- [ ] **齊藤商店の創業年**（外観の黒板看板に「Since 1947」とある。サイトでは「看板にそう書かれている」とだけ書いている）
- [ ] 料金表の税込金額（税抜 × 1.1 で算出して表示している。端数処理や税込の正式な金額が違う場合は `data/pricing.ts` を直す）
- [ ] **スタッフによる使い方レクチャーの範囲**
- [ ] 緯度・経度（構造化データの geo。Google ビジネスプロフィールの値を使う）
- [ ] 利用者の声・実績（実在するものだけ掲載する）
