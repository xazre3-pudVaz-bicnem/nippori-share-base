# コラムの記事候補

これから書く記事の候補です。上から順に書くと、検索での広がりを作りやすい順になっています。
書き方は `content/column/README.md` を参照してください。

記事は 3 種類あります（`content/column/README.md`）。**いちばん増やしたいのは「できごと・お知らせ」（report）**です。
検索向けの読みもの（guide）は、下の候補を急いで埋めるより、できごとの記事と交互に出すくらいがちょうどよいです。

## これから書く「できごと・お知らせ」の例（実際にあったことだけ）

- ○月の編み会をひらきました（日時、内容、使った机の配置）
- このミシンで○○を縫ってみました（機種名、生地、気づいたこと）
- 新しいミシンが入りました／期間限定のミシンのお知らせ
- ○○ワークショップ開催レポート（主催者の了承を得て）
- 今月の Nippori Share Base（予約できる日、イベントの予定）
- 日暮里繊維街の催し（大売り出しなど）に合わせたお知らせ

## これから書く候補

固定ページ（/sewing-machine、/handmade など）は「日暮里で◯◯できる場所を探す人」のためのページです。
コラムは同じ言葉を取り合わないよう、「知りたい・調べたい」に答える内容にして、最後に固定ページへ案内します。

## 書かないほうがよいもの

- 「日暮里 ミシン レンタル おすすめ◯選」のような比較記事（他店の情報を正確に保てない）
- 実在しない利用者の体験談
- 確認できていない設備・料金・営業日に触れる記事
